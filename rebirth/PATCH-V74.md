# Rebirth v7.4

## 스킬 안내

선택창·조작 가이드·전투 HUD·모바일 터치 안내의 원작 Q/W/E/R 표기를 제거했습니다. 실제 게임의 J/K/L/U와 이동·점프 키를 표시합니다. 암베사의 두 번째 강공격은 Q2 대신 후속타/2타로 안내합니다.

## 아처 활 공격

아처 L 화살의 판정 중심은 높이 150, 세로 반폭은 11이어서 아랫면이 139였습니다. 축소된 카티야의 피격 범위 상단은 137.76이라 1.24 월드 좌표의 틈이 생겨 서 있는 카티야도 통과했습니다.

실제 발사 그림의 화살촉은 높이 약 140~142에 있습니다. 발사 중심을 고정 높이 **140**으로 맞추고 차징 효과도 같은 기준으로 연결했습니다. 피해·속도·사거리·가로 위치·판정 크기는 그대로이며 카티야의 피격 범위를 확대하지 않았습니다. 높이는 월드 좌표이고 실제 내부 화면에서는 절반입니다.

## 카티야 선택 일러스트

제공한 참고 그림을 바탕으로 머리·어깨의 화면 내 비중을 줄이고 허리까지 보이는 구도로 다시 제작했습니다. 안경 없는 모습, 굵은 윤곽선과 간결한 색면을 유지합니다. 다른 13명의 선택 일러스트 파일은 그대로입니다. 내장 ImageGen의 정확한 생성·수정 프롬프트와 원본은 전체 소스의 `art-source/v74-portraits/`에 들어 있습니다.

## 검증

14명 모두 선택·훈련 HUD·터치 문구를 검사했고, 암베사는 실제 첫 K 적중 후 후속타 표시도 확인했습니다. PC 1440×1040·모바일 390×844의 새 카티야와 암베사 패널에서 겹침·가로 넘침·브라우저 오류는 없었습니다.

전체 `npm test`는 **118/118 통과**했습니다. 수정 전후 각각 440개의 활 공격 상황을 재현했고, 카티야의 지상·가드·이동·K/L 입력 72건에서 빗나감이 정상 명중·가드로 바뀌었습니다. 다른 13명의 지상·가드 312건은 결과·피해·접촉 프레임이 동일했습니다. 카티야의 점프 회피와 대시 무적도 확인했습니다.

실제 Chromium에서도 동일 거리의 한 발을 비교했습니다. 기존 높이는 피해 0, 수정 높이는 피해 119였고 브라우저 오류는 없었습니다. [전투 검증](docs/archer-katja-v74.md) · [화면 비교](docs/archer-katja-v74.png) · [UI 검증](docs/ui-validation-v74.json).

## 실행

실행 ZIP을 새 폴더에 완전히 풀고 `start_rebirth.bat`를 실행하세요. Node.js 22 이상이 필요하며 화면의 **v7.4 / 14 FIGHTERS** 표시를 확인하세요. 기존 배포 사이트는 이 ZIP 실행만으로 자동 갱신되지 않습니다.
