# Rebirth v7.4 — 14 Fighters

아케론·부트힐을 포함한 14인 실행용 패키지입니다. v7.4는 스킬의 원작 단축키 표기 제거, 아처 활 공격 높이 수정, 참고 그림에 맞춘 카티야 선택 초상화 교체를 포함합니다.
게임에 필요한 코드·이미지는 모두 포함되어 있습니다. 아트 제작 원본과 개발용 영상은 제외했습니다.

## Windows 실행

1. ZIP을 새 폴더에 완전히 압축 해제합니다. ZIP 안에서 바로 실행하지 마세요.
2. Node.js 22 이상이 설치된 상태에서 `start_rebirth.bat`를 실행합니다.
3. 처음 실행할 때 필요한 패키지를 설치하며 인터넷 연결이 필요합니다.
4. 새 서버가 준비되면 브라우저가 자동으로 열립니다. 이 페이지의 `14 FIGHTERS / v7.4` 표시를 확인하세요.
5. 게임을 하는 동안 서버 창을 켜 두세요. 종료하려면 그 창에서 Ctrl+C를 누릅니다.

기존 서버가 기본 주소를 사용 중이면 새 실행기는 다른 빈 포트를 사용합니다.
주소를 직접 열어야 한다면 실행 창의 `Open:` 뒤에 나온 주소를 복사하세요.
이전 탭이나 북마크의 주소는 계속 이전 서버를 가리킬 수 있습니다.
이 실행기는 기존 서버를 종료하거나 그 서버의 파일을 수정하지 않습니다.

## 터미널 실행

```sh
npm ci
npm run play
```

브라우저를 자동으로 열지 않으려면 `node rebirth/launch.mjs --no-open`을 사용합니다.
서버 배포용 명령 `npm run rebirth`는 기존처럼 고정 포트 또는 PORT 환경변수를 사용합니다.
이 패키지를 로컬에서 실행해도 이미 배포된 Render 사이트가 자동으로 업데이트되지는 않습니다.

## 조작

- 이동: A/D, 점프: W, 가드: S
- 약공격: J, 강공격: K, 스킬: L, 궁극기: U, 회피: Space
- 아케론: U로 강화 후 J를 세 번 각각 누르면 자동 마무리
- 부트힐: J 사격, K 밀어내기, L 대치·3연발 강화, U 결정타
- 암베사: 첫 K 적중 후 K를 다시 눌러 2타
- 매그너스: 바이크 탑승 중 U를 다시 눌러 발사

메두사·이스칸다르는 U로 8초 탑승한 뒤 L 또는 U로 돌진합니다. 돌진 재사용 시간은 각각 1.75초·2.2초입니다. 새 사운드나 보이스는 추가하지 않았습니다.

로비는 초상화를 먼저 표시하고 전투 그림을 따로 준비합니다. 전투 그림을 불러오지 못하면 로딩 화면에서 다시 시도할 수 있습니다.

상세 조작은 게임 상단 조작 가이드에서 확인할 수 있습니다.
